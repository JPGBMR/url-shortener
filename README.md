# URL Shortener

[![Live Demo](https://img.shields.io/badge/Live%20Demo-jpgbmr.github.io-58a6ff?style=flat-square)](https://jpgbmr.github.io/url-shortener/)
[![HTML](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)](https://github.com/JPGBMR/url-shortener)

Paste a long URL, get a short one instantly. QR code included. History saved locally. Nothing uploaded.

## Getting Started

Open `index.html` in your browser. No install required.
